# Security Policy

We take the security of Wardens Protocol seriously. If you find a security issue, please report it immediately via the process outlined below.

## Supported Versions

Only the latest release (and main branch) is actively supported for security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security-related bugs.**

To report a vulnerability, please send an email to the project maintainers or security contact (e.g., at your contact address linked to your buildathon submission). 

Please include:
1. A detailed description of the vulnerability.
2. Step-by-step instructions to reproduce the issue.
3. Potential impact or exploit scenarios.

We will acknowledge receipt of your report within 48 hours and work with you to coordinate a security patch and public advisory.
